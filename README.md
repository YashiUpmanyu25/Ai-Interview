# AI Mock Interview

A Next.js app for practicing interviews with an AI interviewer: 3D avatar, speech recognition, resume upload, live feedback, and a progress dashboard.

## Getting Started

```bash
npm install
cp .env.example .env.local   # then fill in your keys
npm run dev
```

Open http://localhost:3000.

## Environment Variables

See `.env.example`: MongoDB, JWT secret, and API keys for Gemini, OpenRouter, D-ID and Murf.

## Scripts

- `npm run dev` – start dev server
- `npm run build` – production build
- `npm test` – run tests (Vitest)
