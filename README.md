# AI Mock Interview

A full-stack Next.js app for practicing interviews with an AI interviewer. Pick a topic, answer by voice or text, and get scored AI feedback with history and analytics.

## Features

- Signup and login (bcrypt password hashing, JWT in httpOnly cookies) with protected pages
- Interview topics: DSA, React, System Design, Backend, HR, DBMS, OOPs
- Questions generated by an LLM (OpenRouter), with built-in fallback questions if the API fails
- 3D talking AI interviewer (TalkingHead, Three.js) with Edge TTS voice
- Voice answers via the Web Speech API, live transcription panel, webcam and mic preview, and an interview timer
- AI analysis of answers: per-question score, correct approach, improvements, strengths, weaknesses and skill breakdown
- Feedback page with question-by-question review and a downloadable PDF report
- Dashboard, interview history, and analytics (score distribution, skill breakdown, weekly performance)
- Resume upload with PDF text extraction (OCR fallback for scanned files) and AI-generated resume-based questions
- Settings: profile, password change, notification preferences
- Demo page

## Tech Stack

Next.js 16 (App Router), React 19, TypeScript/JavaScript, Tailwind CSS, Zustand, Framer Motion, MongoDB (Mongoose), Three.js / React Three Fiber, OpenRouter (OpenAI SDK), pdf-parse, Tesseract.js, PDFKit, Vitest, React Testing Library

## Getting Started

```bash
npm install
cp .env.example .env.local   # then fill in your values
npm run dev
```

Open http://localhost:3000.

## Environment Variables

Required:

- `MONGODB_URI` – MongoDB connection string
- `JWT_SECRET` – any long random string
- `OPENROUTER_API_KEY` – from https://openrouter.ai/keys

Optional (backend routes for D-ID/Murf avatar generation, not used by the main interview page):

- `MURF_API_KEY`
- `DID_API_KEY`
- `AVATAR_IMAGE_URL`
- `NEXT_PUBLIC_APP_URL` – defaults to `http://localhost:3000`

## Scripts

- `npm run dev` – start dev server
- `npm run build` – production build
- `npm start` – run production build
- `npm test` – run tests (Vitest)
- `npm run lint` – run ESLint
